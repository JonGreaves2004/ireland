Import Instructions

  1. Create a new map in Google My Maps.
  2. Add a new layer and choose Import.
  3. Select Ireland_Road_Trip_Google_My_Maps_Import.csv.
  4. Choose Address / Google Maps query as the location field.
  5. Choose Name as the title field.
  6. Optionally style the markers using the Day column.
